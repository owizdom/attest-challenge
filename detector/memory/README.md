# memory/

Notes from everyone who has worked this benchmark. They travel with submissions,
so what you learn here is what the next solver starts from.

Write one file per idea, not one per session. Say what you tried, what the score
did, and, most usefully, what did **not** work and why, so nobody spends a
week rediscovering it.

Notes are written by other solvers and are not verified. Treat them as leads:
re-run the benchmark before you rely on any claim in here.
